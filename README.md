Personal Expense and Budget Tracker
A simple, beginner-friendly 12th-grade Python project that helps users record, view, delete, and analyze daily expenses. The program uses a CSV file to store entries and includes optional matplotlib graphs for category-wise and monthly summaries.

This project demonstrates file handling, data structures, user input processing, and basic data visualization in Python.

✨ Features

Add Expense : Store date, category, and amount into a CSV file (manager.csv).

View Expenses : Display all stored expenses with running total.

Delete Expense : Remove an entry using its Index number

Summary : Shows:

Total amount spent

Spending categorized by type (Food, Travel, Misc, etc.)

Plots (Optional) : If matplotlib is installed:

Category-wise bar chart

Monthly spending line chart

Avoiding File Related Errors : The program automatically creates the CSV file if it's missing.

🛠️ How to Run the Project :

Install Matplotlib , it is optional for graphs (run pip install matplotlib in terminal of your pc)
Run the program
Follow The Instructions showed in the menu
🎓 Concepts Used : This project demonstrates:

Reading & writing CSV data : Using DictReader and DictWriter

Functions & Modular Code: Each feature is handled using its own function.

Error Handling : Avoiding errors due to wrong inputs.

Data Visualization : Simple graphs using matplotlib.

Data Processing :

Adding/Deleting of Entries
Total of all the Expenses Made
Categories of Expenses
Expenses Divided by Months
